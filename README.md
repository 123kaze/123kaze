## Featured work

### [RepoOps Agent](https://github.com/123kaze/RepoOpsAgent)

Evidence-first repository maintenance built on nanobot, with 15 domain tools, code-maintained Agent Status Bar, auditable trajectories, human approval gates, and public benchmark adapters. Repository search now follows an **rg-first** policy: exact symbols and errors use ripgrep; BM25 + trigram is reserved for natural-language and multi-file recall.

### [AZAZ Go](https://github.com/123kaze/azazGo)

Go-Zero microservices for an audio/video social platform, using gRPC, Protobuf, etcd, MySQL, Redis, Kafka, and Elasticsearch. The backend includes cursor-based feeds, batch RPC aggregation, caching, and asynchronous search indexing.

### [Trivy contribution](https://github.com/aquasecurity/trivy/pull/10978)

Open pull request that traces malformed-input panics across Analyzer → Scanner → Detector → OS Driver, adds boundary validation, and covers the affected parser paths with regression tests.
