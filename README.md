## 代表项目

### [RepoOps Agent](https://github.com/123kaze/RepoOpsAgent)

基于 nanobot 构建的仓库维护 Agent，提供 15 个领域工具、代码维护的 Agent Status Bar、可审计工具轨迹、人类审批门禁与公开评测适配器。检索采用 **rg-first** 策略：精确符号和错误信息优先使用 ripgrep，BM25 + trigram 用于自然语言与跨文件召回。

### [AZAZ Go](https://github.com/123kaze/azazGo)

基于 Go-Zero 的音视频社交微服务系统，使用 gRPC、Protobuf、etcd、MySQL、Redis、Kafka 与 Elasticsearch，实现游标分页、批量 RPC 聚合、缓存和异步搜索索引。

### [Trivy 开源贡献](https://github.com/aquasecurity/trivy/pull/10978)

沿 Analyzer → Scanner → Detector → OS Driver 调用链定位异常输入 panic，在边界处增加校验，并为受影响的解析路径补充回归测试。
